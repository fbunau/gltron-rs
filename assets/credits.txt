# glTron-rs

**Ported to Rust and enhanced by** *Florin Bunau*

I have fond memories of playing the original game with my friends on split screen back in the day.

So I thought it is the best use case to learn some Rust and see how far AI agent productivity goes.

Check out the project page at: https://github.com/fbunau/gltron-rs

And the original page at: http://www.gltron.org/
